# vedette-evidence-mcp

A small MCP (Model Context Protocol) server, built to close a specific,
honest gap: hands-on experience authoring an MCP server with real tools.

## What it is

A working MCP server exposing three tools over stdio:

- **search_evidence**: keyword search over a seeded set of evidence chunks,
  each traceable to a named source document.
- **list_opportunities**: lists opportunities, each linked to the evidence
  chunk IDs that support it.
- **compute_roi**: deterministic ROI math (hours saved, adoption ramp,
  annual dollars saved). The model may propose the inputs; every dollar
  figure is computed in plain TypeScript, never generated by a model. This
  mirrors the same model/computation separation used in Vedette.

## What it is honestly

This is a demo project with seeded, fictional data (`src/data.ts`), built to
learn and demonstrate the MCP authoring pattern: defining tools with Zod
schemas, running a stdio transport, and having a client actually call them.
It is not connected to a live database or a real Finance system.

Verified end to end: `test-client.mjs` connects a real MCP client to the
built server, lists the tools, and calls all three. Re-run it any time with
`node test-client.mjs`.

## Running it yourself

```bash
npm install
npx tsc
node test-client.mjs
```
